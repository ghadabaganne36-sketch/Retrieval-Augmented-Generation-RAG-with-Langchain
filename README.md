# Agentic RAG System with LangChain and IBM Granite

## Overview
Implementation of an Agentic Retrieval-Augmented Generation (RAG) system using LangChain and IBM Granite LLM.

The system enables an AI agent to retrieve external knowledge and generate context-aware answers.

## Technologies

- Python
- LangChain
- IBM Granite LLM
- Retrieval-Augmented Generation (RAG)
- Generative AI
- Google Colab

## Features

- Document retrieval
- Context-aware question answering
- LLM-based reasoning
- Agent workflow implementation

- AI Agents
